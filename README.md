# YouTube Clone - Learning Project

This is my first project while learning Web Development.

A simple YouTube UI clone built with HTML and CSS to practice layouting.

### Built With:
- HTML5
- CSS3

### What I Learned:
- Building complex layouts with Flexbox and Grid
- Cloning a real-world website UI
- Basic responsive web design

### Limitations:
This is a frontend-only clone. No JavaScript functionality yet. Video playback and search are for display purposes only.

### Future Improvements:
- Add JavaScript for interactivity
- Make it fully responsive
- Add more pages

This project is part of my learning journey to become a web developer.
